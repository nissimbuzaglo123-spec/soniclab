חשבון וואטסאפ עסקי אצל Meta

אצלך

כשעה עבודה · חינם · דורש חשבון פייסבוק עסקי

זה החלק הכבד היחיד, וכדאי שתדע אותו מראש: שליחת וואטסאפ אוטומטית דורשת WhatsApp Business Cloud API של Meta. אפליקציית וואטסאפ עסקי מהטלפון לא מספיקה — היא לא יודעת לקבל פקודות ממערכת חיצונית.

  1. נכנסים ל־business.facebook.com ופותחים חשבון עסקי לנשק פוינט.
  2. ב־developers.facebook.com יוצרים אפליקציה ומוסיפים לה את המוצר WhatsApp.
  3. מוסיפים מספר טלפון עסקי. חשוב: מספר שאינו רשום כרגע באפליקציית וואטסאפ רגילה.
  4. שומרים שני ערכים שתצטרך בשלב 3: Phone Number ID ו־Permanent Access Token.

03

חיבור הפרטים ב־n8n

אצלך · 5 דקות

אחרי שהתבניות אושרו

נכנסים ל־ה־workflow. בשני צמתי הוואטסאפ יש כרגע שדות מסומנים כממתינים למילוי — לוחצים על כל צומת וממלאים:

  • Credential — יוצרים אחד חדש מסוג WhatsApp ומדביקים את ה־Access Token משלב 1.
  • Phone Number ID — הערך משלב 1, זהה בשני הצמתים.
  • Template — בצומת ההתראה בוחרים new_lead_alert, בצומת התודה lead_thank_you.
  • Recipient Phone Number — רק בצומת ההתראה: המספר שלך בפורמט בינלאומי, למשל 972501234567. בצומת התודה השדה כבר ממולא אוטומטית במספר של הלקוח.

05

הפעלה ובדיקה חיה

אצלך · 2 דקות

השלב האחרון

  1. מעבירים את ה־workflow למצב Active בכפתור שבפינה העליונה.
  2. ממלאים את הטופס באתר עם המספר האישי שלך.
  3. מוודאים ששתי ההודעות הגיעו — ההתראה אליך והתודה ללקוח.

אם משהו לא הגיע, נכנסים ללשונית Executions ב־n8n. כל הרצה מוצגת שם עם הצומת המדויק שנכשל וההודעה שחזרה מ־Meta. שלח לי צילום מסך של הצומת האדום ואומר לך מה לתקן.

אם ההרשמה ל־Meta נראית לך כמו הרבה

יש קיצור דרך. טלגרם נותן בדיוק את אותה התראה מיידית אליך, בהקמה של שתי דקות, בלי חשבון עסקי ובלי אישורי תבניות: פותחים בוט אצל BotFather ומעתיקים טוקן. זהו.

ההבדל היחיד הוא שטלגרם מתאים להתראות פנימיות אליך, לא להודעות ללקוחות — הלקוחות שלך נמצאים בוואטסאפ. אפשר להתחיל מטלגרם כדי לראות את האוטומציה עובדת כבר היום, ולהוסיף את הוואטסאפ ללקוחות אחרי שהחשבון אצל Meta מוכן. תגיד לי ואוסיף את הענף.

מה שכבר בוצע: חמשת שלבי ה־workflow בנויים ומחוברים, נרמול הטלפון נבדק בהרצה חיה שעברה בהצלחה, שני פתקי הסבר הוצבו על הקנבס, וקובץ טופס מוכן נשמר בפרויקט. ה־workflow שמור בפרויקט האישי שלך ב־n8n וממתין כבוי עד שתשלים את שלב 3.
